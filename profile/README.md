<h2>误区一：只比月费，不比超量单价</h2>
<p>套餐内的价格是入场券，超量后的单价才决定长期账单。同样是每月一百多的方案，A 家超出后按每 GB 十几元计费，B 家按每 GB 三四十元计费，用量一旦翻倍，总价差距会迅速拉开。询价时把「超出后怎么算」问到底：是按 GB、按 Mbps、按并发，还是直接停服。</p>
<p>正确做法是先估一个月的实际用量，再套两个方案算总价。用量不确定时，按过去峰值上浮三成估，比按平均值估稳妥。</p>

<h3>要问清的三句话</h3>
<p>超出套餐后按什么单位计费、单价多少；是否自动续量还是需要手动加购；停服是软限速还是直接拒绝请求。三句话的答案直接决定预算上限。</p>

<h2>误区二：把标称带宽当可用带宽</h2>
<p>宣传页的「100 Mbps」在共享节点上通常指整条出口的上限，不是你的保证值。晚高峰实测往往会打对折甚至更低。比价时不要比标称值，要比「晚高峰实测吞吐」和「是否独享」。</p>
<p>验证方法很直接：在同一时段分别用两个方案下载同一个大文件，记录平均速率与波动。差一倍以上的，价格再低也要重新算账。</p>

<h3>共享与独享的价差怎么看</h3>
<p>独享的溢价通常在 30% 到一倍之间，取决于地区与带宽。判断值不值，看这条线承载的业务是否对抖动敏感：实时对话和演示环境值得，离线批处理不值。</p>

<h2>误区三：并发单位混着比</h2>
<p>有的报价说「50 并发」，指连接数；有的指同时请求数；还有的指可登录账号数。单位不同，价格没有可比性。询价时统一成「同一秒内未完成的请求数」，并要求写入订单备注。</p>
<p>另外确认超出并发后的行为：排队、限速还是报错。排队对体验影响最小，直接报错最伤业务，同一价格下优先选排队策略。</p>

<h3>把重试算进并发</h3>
<p>三层重试的脚本，实际占用是名义并发的近三倍。按名义值买，故障时会瞬间打满。预算里留 1.5 倍余量是常见做法。</p>

<h2>误区四：不算替换成本与停机成本</h2>
<p>替换成本包含两部分：换 IP 的手续费，以及换线期间业务中断的损失。前者写在合同里，后者藏在你的业务流程里。一条每月两百元但一个月要换两次的线路，实际成本远高于每月三百元但半年不换的线路。</p>
<p>停机损失可以粗算：受影响人数 × 每小时产出 × 中断小时数。哪怕按保守口径算，一次两小时的中断往往就超过一个月的价差。</p>

<h3>合同里必须写明的两条</h3>
<p>一是 IP 被替换的触发条件与是否收费；二是故障响应时限与补偿方式。这两条不谈清楚，出事时只能靠沟通能力，而沟通能力不能进预算表。</p>

<h3>替换频率怎么看</h3>
<p>问服务商要一个数：过去三个月该 IP 段的平均替换次数。愿意给数字的通常运维做得比较细；只回答「很少」的，按最坏情况估。</p>

<h2>误区五：年付折扣、杂费与榜单，都不在报价单上</h2>
<p>年付常见折扣在一到两个月之间，看着划算，但前提是你真的会用满一年。业务调整、地区变更、规模缩减都会让预付变成沉没成本。规模未定的阶段，季付或月付更灵活。</p>
<p>杂费方面，跨境支付的手续费、汇兑损失、发票形式带来的税差，都可能吃掉折扣。把这些折成人民币加进总价，再和年付方案比，结论常常反转。</p>

<h3>一张可比的总价表</h3>
<p>把五个方案放在同一张表里，列统一为：月费、超量单价、替换费、预估停机损失、杂费。加起来才是可比价格，其余宣传口径一律不看。</p>

<h3>别用「排名」代替实测</h3>
<p>各类榜单的评测口径、采样时段、甚至商业关系都不透明，用作初筛可以，用作决策不行。真正可比的是你自己在同一时段、同一目标上跑出来的三组数据：延迟中位数、晚高峰丢包、连续可用率。</p>
<p>更省事的做法是同时申请两家试用，并行跑三天，用同一张记录表对比。试用的时间成本远低于选错的返工成本。</p>

<h3>试用期该测什么</h3>
<p>别只测连通。测晚高峰吞吐、测连续两小时的稳定性、测一次真实的业务闭环（登录、对话、长文生成）。三项都过，再谈价格。</p>

<h2>常见问答</h2>
<h3>月费差一倍，贵的那个一定更好吗？</h3>
<p>答：不一定。价差可能来自独享程度、地区稀缺性或售后投入，也可能只是品牌溢价。用总价表算一遍，再看晚高峰实测数据，才能判断多付的钱买到了什么。</p>
<h3>年付折扣一般能到多少？</h3>
<p>答：常见在一到两个月的额度，具体随服务商与采购量变化，仅供参考。折扣再高也要先确认替换政策与退款条款，否则预付反而锁死了调整空间。</p>
<h3>超量计费按流量还是按带宽更划算？</h3>
<p>答：用量波动大的选按流量，平稳且高的选按带宽。两者临界点大致在「月流量稳定超过套餐两倍」附近，超过这个量，固定带宽通常更便宜。</p>
<h3>怎么判断报价里的并发是不是虚标？</h3>
<p>答：让对方写清单位，并做一次压测：并发发起请求，观察第 90 百分位响应时间与错误率。真实并发能力在压测下会立刻显形，口头承诺不会。</p>
